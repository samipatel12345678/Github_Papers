## 📊 Project Overview

```
SYSTEM: AI Feedback Loop for Article Writing
AGENTS: 4 specialized AI agents (Researcher, Writer, Critic, Feedback)
FLOW:   Research → Write → Critique → Feedback → Loop (max 3x)
API:    Express.js backend on port 5000
UI:     React + Vite frontend on port 5173
LLM:    Anthropic Claude 3.5 Sonnet
SPEED:  ~2-5 minutes per full cycle
```

---

## 🔄 How It Works

```
User Topic
   ↓
[Session Created]
   ↓
RESEARCHER AGENT
→ Searches & gathers information
→ Returns research summary
   ↓
WRITER AGENT
→ Uses research to write article
→ Returns complete article
   ↓
CRITIC AGENT
→ Reviews article quality
→ Returns detailed feedback
   ↓
FEEDBACK AGENT
→ Analyzes feedback
→ Decides: Improve? or Done?
   ↓
DECISION
├─ Loop Back (Iterations < 3) → Back to Writer
└─ Complete (Iterations = 3) → Return Final Article
   ↓
[Article Ready for Publishing]
```
