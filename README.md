# 🗂️ Github_Papers

A centralized workspace and dumpground for multiple standalone projects, where each project lives entirely on its own dedicated Git branch.

---

### 📌 How It Works
- **One Branch = One Project**: Every branch hosts an independent codebase with its own dependencies, runtime, and dedicated `README.md`.
- **Zero Cross-Pollution**: Projects evolve in isolation without merge conflicts or shared files.
